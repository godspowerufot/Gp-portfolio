# Godspower Ufot — Portfolio

Minimal, editorial portfolio built with Vite, React, React Router, and Tailwind CSS v4.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/pages/Home.jsx` — main landing page (Hero, Projects, About, Experience, Tech Stack, Contact)
- `src/pages/CaseStudy.jsx` — project case study page, routed at `/project/:slug`
- `src/data/projects.jsx` — all project cards and case study content
- `src/components/` — Nav, Footer, Reveal (scroll animation)
- `src/sections/` — home page sections
